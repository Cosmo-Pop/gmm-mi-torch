## <kbd>function</kbd> `log_gauss`

```python
log_gauss(X, mu, chol)
```

Component-wise Gaussian log-densities.

X: (R,N,d), mu: (R,K,d), chol: (R,K,d,d) lower.  Returns (R,N,K).

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `X` | `torch.Tensor of shape (R, N, d)` | Points, per replicate. |
| `mu` | `torch.Tensor of shape (R, K, d)` | Component means. |
| `chol` | `torch.Tensor of shape (R, K, d, d)` | Lower Cholesky factors of the component covariances. |

### Returns

| Return Value | Type | Description |
|--------------|------|-------------|
| - | `torch.Tensor of shape (R, N, K)` | Log-density log N(x_n \| mu_k, chol_k chol_k^T). |

## <kbd>function</kbd> `marginal_params`

```python
marginal_params(mu, cov, idx)
```

Analytic marginal of a GMM onto a variable subset.

A GMM's marginals are GMMs: component weights are unchanged and the
means/covariances are index-masked — this is what keeps every marginal
exactly consistent with the joint fit.

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `mu`, `cov` | `torch.Tensor` | Joint means (R, K, d) and covariances (R, K, d, d). |
| `idx` | `sequence of int` | Variable indices to keep. |

### Returns

| Return Value | Type | Description |
|--------------|------|-------------|
| `mu_m`, `cov_m` | `torch.Tensor` | Marginal means and covariances over the subset. |
